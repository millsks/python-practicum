How this course works

1 · Read and run

Every lesson mixes explanation with runnable cells. Edit the code and press Ctrl/⌘+Enter. Real CPython 3.14 runs in your browser.

2 · Predict and watch

Predict-the-output cells, the step-through tracer, and animated visualizers show what the computer actually does.

3 · Practice

Graded exercises check your code with tests. Hints and solutions are there when you need them.

4 · Prove it

Each module ends with a quiz, flashcards, and a mini-project you build locally.

5 · Build

Each part ends with a graded project in this repository: pixi run start p01, then pixi run grade p01.

6 · Ship

The capstone combines algorithms, data engineering, and ML into a real application with professional tooling.

All local work uses Pixi. From the repository root: pixi install once, pixi run serve to open this site, pixi run projects to list projects, pixi run start p01 to copy a starter into work/, and pixi run grade p01 to run its tests.

Plan on about 8–10 hours a week. At that pace the full curriculum takes roughly 9–12 months. Don't skip the exercises and projects. Real skill comes from writing code, not just reading it.
