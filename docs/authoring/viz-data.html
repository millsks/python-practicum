Concurrency, Data, and ML Visualizers

Every visualizer in viz-data.js, mounted with a few configurations. Copy the markup into a module page.

⏱ 15 minPrerequisites: none
  • See each data and ML visualizer working

event-loop

Three downloads on one timeline. scenario is sequential, asyncio, or threads. The controls also switch between the standard (GIL) and free-threaded 3.14t builds and between I/O-bound and CPU-heavy work (optional extra keys: build: gil | free-threaded, workload: io | cpu).

<div class="viz" data-viz="event-loop" data-config='{"scenario": "asyncio"}'></div>

gradient-descent

fn is quadratic, bowl, or rosenbrock; lr sets the starting learning rate (optional momentum: true). Click the plot to choose a start point.

<div class="viz" data-viz="gradient-descent" data-config='{"fn": "quadratic", "lr": 0.1}'></div>

kmeans

k (2 to 6) and optional points (an array of [x, y] pairs, rescaled to fit). Optional init: random | kmeans++.

<div class="viz" data-viz="kmeans" data-config='{"k": 3}'></div>

neural-net

layers lists the layer sizes, such as [2, 3, 1]. Forward-pass mode animates activations layer by layer; training mode learns XOR with backpropagation (optional mode: forward | train).

<div class="viz" data-viz="neural-net" data-config='{"layers": [2, 3, 1]}'></div>

pipeline

stages names the ETL stages (default ["extract", "validate", "transform", "load"]). Optional mode: streaming | batch and write: upsert | append. Press Re-run same input to see why idempotent loads matter.

<div class="viz" data-viz="pipeline" data-config='{"stages": ["extract", "validate", "transform", "load"]}'></div>
